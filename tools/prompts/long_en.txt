WebGPU is a modern graphics and compute API for the web. It exposes the capabilities of contemporary GPUs, such as compute shaders, storage buffers and explicit pipelines, to JavaScript and WebAssembly. Compared with WebGL, it maps more directly onto Vulkan, Metal and Direct3D 12, which reduces driver overhead and makes general-purpose GPU programming practical in the browser. Machine learning inference is one of the most important use cases: small language models with a few billion parameters can now run entirely on the client, which protects privacy and removes server costs. However, the performance of such inference depends heavily on how well the kernels are written for the specific model architecture and on how memory bandwidth is used. Quantization to four bits, fused kernels, and careful scheduling of dispatches all matter.
